## Explore a what-if scenario

In Card view, expand a decision or uncertainty and select an option or outcome. Selecting an option forces that decision; selecting an outcome treats it as hard evidence. Selections can be combined across issues. Select the same state again to deselect it, or select another state on that issue to replace it. In Shape view, hover over a decision or uncertainty and use its states control to make the same selections.

The toolbar shows **Base EV** for the unconditioned model and **Scenario EV** for the selected states; the delta is Scenario EV minus Base EV. Wait for recalculation and check for warnings. A scenario is a conditional exploration, not a change to the model's probability inputs or a guaranteed outcome. Clear all selections to return to the baseline.
