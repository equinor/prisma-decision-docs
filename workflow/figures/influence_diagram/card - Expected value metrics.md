## Review model value metrics

Read the toolbar's expected-value metrics to inspect the model's calculated results. An expected value is not a guaranteed outcome. Check whether node outcomes are selected for conditional exploration, and clear unintended selections before interpreting an unconditional baseline. After editing inputs, wait for recalculation and review warnings before relying on the displayed values.
