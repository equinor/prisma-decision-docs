## Structure the influence diagram

Use the influence diagram to represent decisions, uncertainties, utilities, and their relationships. Arrows into a value node specify value dependencies; arrows into a decision specify information available before choosing; arrows into an uncertainty require the corresponding conditional probabilities. Do not add an information arrow merely to make a connection: it changes what the decision is allowed to know.

![Influence diagram page](<./page - Influence diagram.png>)

> [!WARNING]
> An arrow on an influence diagram only means a possible relationship. The absence of an arrow means no possible direct relationship. Therefore, an absence of arrow is a stronger message than the presence of one.
