## Enter values in a utility table

When a value depends only on one decision or uncertainty, enter its contribution in the **Utility** field for each option or outcome in the issue editor; a separate Utility issue is not accepted by Prisma. See the Issues guide for editing issue details.

When a value depends jointly on two or more issues, create a **Utility** issue and connect each parent to it. In Card view, open the Utility issue's **Issue actions** menu and select **Utility Table**. Each row represents a combination of parent states; enter its value under **Default metric** and leave the cell to save. State utilities and Utility tables both contribute additively to the model's total value, so do not count the same effect twice.
