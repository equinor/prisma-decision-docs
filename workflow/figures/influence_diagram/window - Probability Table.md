## Review uncertainty probabilities

Enter probabilities as fractions from 0 to 1, not percentages: use 0.4 rather than 40 for 40%. Leave each edited cell to save it, then check that every applicable parent-state row sums to 1. Complete all required rows; a cell disabled by a restriction is not a missing input to overwrite. Record the evidence behind the estimates in the issue description or decision record.
