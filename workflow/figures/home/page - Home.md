## Find or start a project

Use the home page to find an existing project, create a new project, or import a saved project export. Sign in using the method configured for your deployment: an organizational account for enterprise access, or a non-personal training username where demo access is enabled. Use only non-confidential training data in a demo. An empty list can simply mean no projects are available to the current account.
