## Read the solution tree

Use the solution tree to examine the solved policy and the paths it displays. The example is partially expanded: select a **+** on a branch to reveal the next node, and use the red branch control to collapse it again. Scissors mark pruned branches.

Interpret recommendations in the context of the model's objectives, probabilities, values, and information timing; a recommendation is not a guarantee of the eventual outcome.

![Solution tree page](<./page - Solution tree.png>)

The solution tree is a pruned version of the decision tree only exhibiting the paths corresponding to the optimum course of action.
