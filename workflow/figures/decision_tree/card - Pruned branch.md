## Recognize a pruned branch

The **scissors** symbol marks a **pruned branch**, shown with a dashed connecting line. This path is excluded from further expansion, for example because an outcome has zero probability given the preceding path or a model restriction rules it out. It is not a terminal result, a collapsed branch, or a button for deleting part of the model. Unlike a plus placeholder, it cannot be expanded.
