## Recognize a leaf node

The **envelope-shaped** symbol marks a **leaf (terminal) node**: this path has reached its result, with no further decisions or outcomes to expand. It is not an email action. Read **Value** and, when displayed, **Cumulative probability** beside it. Select the symbol to highlight the complete path to that leaf; select the root node to clear the highlight. A plus placeholder means more detail remains hidden, while scissors indicate a pruned path rather than a terminal result.
